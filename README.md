# BAR_Monobattles
A Unit Picker for the RTS Game [Beyond All Reason](https://www.beyondallreason.info/), inspired by the Monobattles Custom-Gamemode in Starcraft. 

---

Select a Faction - Armada, Legion or Cortex
Select the wanted Unit-Type - Bots, Aircraft, Vehicles, Sea and Hover
Clicking "Pick Units" will pick two random Units, one for each Tier, of the selected Faction and Unit-Type to play. 
Both Units can be rerolled once. 

---

Chosen Units will be shown like so:
- Image
- Name
- Building where to produce the Unit
