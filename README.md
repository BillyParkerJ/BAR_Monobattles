# BAR_Monobattles
A Unit Picker inspired by the Monobattles Custom-Gamemode in Starcraft. 

---
Select a Faction - Armada, Legion or Cortex
Select the wanted Unit-Type - Bots, Aircraft, Vehicles, Sea and Hover

Click "Pick Units" and it will pick two random Units, one for each Tier, of the selected Faction and Unit-Type for you to play. 
Both Units can be rerolled once.
